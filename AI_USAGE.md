# AI Usage Disclosure

This document transparently describes how AI tooling was used in the
development of **Page Pulse**.

## How AI was used

- **Project scaffolding:** Assisted with generating the initial project
  structure, configuration files, and boilerplate setup for the frontend
  and backend.
- **Architecture discussions:** Helped explore approaches for caching,
  concurrency control, error handling, and the client/server interaction.
- **Documentation:** Assisted in drafting the README, design documents,
  inline comments, and this disclosure file.
- **Boilerplate code:** Generated repetitive or mechanical code such as
  shared type definitions and basic configuration.

## What the developer reviewed and customized

- **Core implementation:** Reviewed, modified, and integrated the audit
  pipeline, caching, history tracking, timeout handling, and fallback
  behavior.
- **Error handling:** Refined error responses, timeout behavior, and the
  handling of unreachable URLs for consistent API responses.
- **Testing and debugging:** Reviewed and debugged the application,
  resolved integration issues, fixed backend/frontend communication,
  validated caching behavior, and verified required test scenarios.
- **UI and UX:** Customized the dashboard layout, styling, accessibility,
  responsiveness, and user interactions.
- **Final review:** Reviewed the complete codebase, removed debugging code,
  and validated the application before submission.

## Statement

AI was used as a development assistant for brainstorming, boilerplate
generation, documentation, and debugging support. All generated code was
reviewed, tested, and adapted before being included in the final
submission. The final implementation and submission reflect the
developer's review and decisions.
